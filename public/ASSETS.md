# Visual assets

- `stadium.webp`: optimized stadium photograph from [Unsplash](https://images.unsplash.com/photo-1522778119026-d647f0596c20), resized to 1280 pixels wide and encoded as WebP. The image is stored locally so rendering does not depend on Unsplash availability.
- `fonts/geist-latin.woff2`: Geist variable font distributed with Next.js. The SIL Open Font License is included in `fonts/OFL.txt`; upstream source: https://github.com/vercel/geist-font.
